🗺️ Como estudar com este site

  1. Navegue pelas páginas e teste tudo que é clicável.
  2. Leia o código-fonte: cada arquivo tem comentários explicando o porquê.
  3. Abra o DevTools (tecla F12): inspecione elementos e mexa no CSS ao vivo.
  4. Modifique: mude cores, textos e valores — quebrar e consertar é o melhor jeito de aprender!
💡 Dica: no navegador, clique com o botão direito em qualquer parte do site e escolha "Inspecionar" para ver o HTML e o CSS funcionando em tempo real.
