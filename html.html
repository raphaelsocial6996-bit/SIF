📄 O que é HTML?

HTML (HyperText Markup Language) é a linguagem de marcação que define a estrutura e o conteúdo das páginas. "Marcação" porque você MARCA pedaços do texto com tags dizendo o que cada parte É: <h1> diz "isto é um título", <p> diz "isto é um parágrafo".

💡 Importante: no texto acima escrevemos &lt;h1&gt; para MOSTRAR a tag na tela sem que o navegador a interprete. &lt; vira < e &gt; vira >. Isso se chama entidade HTML.

🔤 Títulos e parágrafos

Existem 6 níveis de título, do <h1> (mais importante) ao <h6> (menos importante). Use-os em ORDEM, como um sumário: isso ajuda o Google e leitores de tela a entender a página.

Título h1 (só 1 por página)

Título h2 (seções)

Título h3 (subseções)

Isto é um parágrafo (<p>). Parágrafos separam blocos de texto com respiro automático.

Dentro de um parágrafo você pode destacar com negrito (<strong> = importante) e itálico (<em> = ênfase).

📝 Listas

<ul> = lista NÃO ordenada (bolinhas, ordem não importa). <ol> = lista ORDENADA (numerada, ordem importa). <li> = cada ITEM da lista (sempre dentro de ul ou ol).

Lista não ordenada (compras):

  • Café
  • Pão
  • Queijo

Lista ordenada (passos):

  1. Ferver a água
  2. Passar o café
  3. Servir

🔗 Links e imagens

<a href="..."> cria um LINK. O atributo href diz PARA ONDE ele vai. Links podem apontar para outra página do site, um site externo ou uma parte da mesma página.

Imagem

<img src="..." alt="..."> exibe uma imagem. src = caminho da imagem. alt = texto alternativo: descreve a imagem para cegos (leitores de tela) e aparece se a imagem não carregar. Sempre preencha o alt!

📊 Tabelas

Tabelas organizam DADOS em linhas e colunas: <table> (tabela) → <tr> (linha) → <th> (célula de CABEÇALHO) ou <td> (célula de DADO). Use tabelas para dados, NUNCA para montar layout!

🧱 Div, span e tags semânticas

<div> = caixa genérica em BLOCO (ocupa a linha toda). <span> = caixa genérica em LINHA (só o tamanho do texto). Elas não dizem NADA sobre o conteúdo — servem para agrupar e estilizar.

Já as tags semânticas dizem o SIGNIFICADO: <header>, <nav>, <main>, <section>, <footer> — todas usadas neste próprio site!

Sou uma <div> (bloco, linha toda). E isto é um <span> (em linha, só envolve o texto).
