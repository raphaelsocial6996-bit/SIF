⚙️ O que é JavaScript?

JavaScript (JS) é a linguagem do COMPORTAMENTO: cliques, animações, cálculos, formulários, jogos... Se HTML é o esqueleto e CSS é a roupa, o JS são os músculos.

A ideia central em 3 passos (vale para TUDO em JS):

// 1. ENCONTRAR o elemento na página (pelo id)
const botao = document.getElementById("meu-botao");

// 2. OUVIR um evento (ex: clique)
botao.addEventListener("click", function () {
  // 3. FAZER algo (ex: mudar um texto)
  alert("Você clicou!");
});
💡 DOM = a página vista como objetos. document é a página inteira; getElementById pega um pedaço dela pelo id; addEventListener diz "quando X acontecer, execute Y". Decore esse trio: encontrar → ouvir → fazer!

📦 Variáveis e funções

Variável = caixinha com nome que guarda um valor. let cria caixinha que PODE mudar; const cria caixinha que NÃO muda (constante). Função = bloco de código com nome, que só executa quando chamado. 

// let: valor PODE mudar (ex: placar de jogo)
let pontos = 0;
pontos = pontos + 10;  // agora vale 10

// const: valor NÃO muda (ex: elemento da página)
const titulo = document.getElementById("titulo");

// function: receita guardada para usar quando quiser
function dobrar(numero) {
  return numero * 2;  // return = resposta da função
}
dobrar(5);  // responde 10

🔀 Exemplo 2: Condicionais (o programa decide)

if / else = "SE ... SENÃO". Na página inicial há uma saudação que muda sozinha: de manhã "Bom dia", à tarde "Boa tarde", à noite "Boa noite". Este é o código real dela: 

const hora = new Date().getHours();  // hora atual (0 a 23)

if (hora >= 5 && hora < 12) {
  saudacao.textContent = "Bom dia!";
} else if (hora >= 12 && hora < 18) {
  saudacao.textContent = "Boa tarde!";
} else {
  saudacao.textContent = "Boa noite!";
}
// && significa "E" (as duas condições verdadeiras)

✅ Exemplo 3: Mini lista de tarefas (teste!)

Digite uma tarefa e clique em Adicionar (ou aperte Enter). O JS CRIA elementos HTML novos (createElement) e pendura na lista (appendChild). Cada ✖ remove seu item. 





    // Resumo do que o JS faz (versão simplificada):
function adicionarTarefa() {
  const texto = campoTarefa.value;      // 1. LÊ o que foi digitado
  const item = document.createElement("li");  // 2. CRIA um <li> novo
  item.textContent = texto;             // 3. coloca o texto dentro
  listaTarefas.appendChild(item);       // 4. PENDURA na lista (aparece!)
  campoTarefa.value = "";               // 5. limpa o campo
}
