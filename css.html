🎨 O que é CSS?

CSS (Cascading Style Sheets) é a linguagem da APARÊNCIA: cores, fontes, tamanhos, espaçamentos, posições e até animações. O HTML diz o que é; o CSS diz como aparece.

Uma regra CSS tem 3 partes — leia o exemplo com calma:

/* seletor { propriedade: valor; } */
.titulo {
  color: blue;       /* cor do TEXTO */
  font-size: 24px;   /* tamanho da fonte */
}

Seletor = QUEM recebe o estilo. Propriedade = O QUE mudar. Valor = COMO.

🎯 Seletores (os 4 essenciais)

Seletores ESCOLHEM quais elementos serão estilizados:

/* 1. Por TAG: afeta TODOS os <p> da página */
p { line-height: 1.6; }

/* 2. Por CLASSE (.nome): afeta quem tem class="nome".
      Pode REPETIR em vários elementos. É o mais usado! */
.destaque { background: yellow; }

/* 3. Por ID (#nome): afeta O elemento com id="nome".
      Deve ser ÚNICO por página. */
#menu { display: flex; }

/* 4. Por ESTADO (:hover): quando o mouse passa por cima.
      Chama-se PSEUDOCLASSE. Não precisa de JavaScript! */
button:hover { background: darkblue; }
💡 Regra de ouro: use classes para estilo (reutilizáveis) e ids para o JavaScript encontrar um elemento específico. Foi exatamente assim que este site foi feito!

🌈 Cores no CSS

As 3 formas mais comuns de escrever cores:

/* Nome da cor (simples, poucas opções) */
p { color: red; }

/* HEXADECIMAL (mais usado: #RRGGBB) */
p { color: #2563eb; }  /* azul deste site */

/* RGB com transparência (a = alpha, 0 a 1) */
p { color: rgba(0, 0, 0, 0.5); }  /* preto 50% transparente */

⬤ Esta frase usa color: red (nome)

⬤ Esta frase usa color: #2563eb (hexadecimal)

⬤ Esta frase usa rgba com 50% de transparência

📦 Box Model (o conceito mais importante do CSS)

Todo elemento é uma CAIXA com 4 camadas, de dentro para fora: conteúdo → padding (respiro interno) → borda → margem (distância externa).

💡 Confundiu margem com padding? Pense numa foto com moldura na parede: o padding é o papelão ENTRE a foto e a moldura; a margem é a distância da moldura até os OUTROS quadros.

📱 Responsividade (site que se adapta ao celular)

Sites modernos usam media queries: regras CSS que só valem em certo tamanho de tela. É assim que este site transforma o menu em ☰ no celular. Teste: diminua a janela do navegador e observe! 

/* "Se a tela tiver ATÉ 640px, aplique estas regras" */
@media (max-width: 640px) {
  .botao-menu {
    display: block;  /* mostra o botão ☰ */
  }
  .menu {
    display: none;   /* esconde o menu (JS reabre ao clicar) */
  }
}
